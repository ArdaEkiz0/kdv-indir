Transparency: SBOM and security scanning

Every third-party component inside the application (libraries and native runtimes included) is published in the SBOM.json list. The list is CycloneDX 1.5 and is extracted directly from the shipped package: each component’s version, licence and dependencies, plus the SHA-256 of the native runtime files.

If your antivirus flags the file (ESET, Defender)

The application is not digitally signed yet, so some antivirus products raise a false positive on a packaged, unsigned program and may quarantine it. The file is clean; its only source is the GitHub link on this page.

ESET: Settings → Virus and spyware protection → Exclusions → Add path: %LOCALAPPDATA%\Programs\KDV Kontrol. Then add KDV Kontrol.exe under HIPS → Excluded applications. Restore the quarantined item or run the installer again.

Microsoft Defender: Windows Security → Virus & threat protection → Manage settings → Exclusions → Add exclusion → Folder: %LOCALAPPDATA%\Programs\KDV Kontrol.

We also reported the false positive to the vendors; once their signature is updated you can remove the exclusion. If your antivirus still blocks it, send us the detection name and time so we can add it to our report: ardaekiz72@gmail.com.

If Windows shows a warning

The application does not have a code signing certificate yet, so Windows SmartScreen may show an “unknown publisher” warning. If you downloaded the file only from the link on this page, you can continue: More info → Run anyway.

Updates

You can check for updates from inside the application. Every update package passes three gates: the Ed25519 signature, then the SHA256SUMS.txt digest, and finally the file's own SHA-256 digest. If verification fails, the update is not installed.

Uninstalling

Control Panel → Programs and Features → KDV Cross-Check → Uninstall. Alternatively run unins000.exe from the installation folder. Uninstalling removes the application and its files completely; the invoice and report files on your computer are untouched.

System requirements

  • Windows 10 or 11 (64-bit)
  • About 500 MB of disk space (including installation)
  • Internet is only needed for licence verification and updates; the comparison itself works offline
