Transparency: SBOM and security scanning

Every third-party component inside the application — libraries and native runtimes included — is published in the SBOM.json list. The list is CycloneDX 1.5 and is extracted directly from the shipped package: each component’s version, licence and dependencies, plus the SHA-256 of the native runtime files.

You can also inspect the files with independent security engines. The VirusTotal links open by the file’s SHA-256. In the scan of 2 November 2026:

If Windows shows a warning

The application does not have a code signing certificate yet, so Windows SmartScreen may show an “unknown publisher” warning. If the SHA-256 digest of the file you downloaded matches the value above, the file has not been altered. To proceed: More info → Run anyway.

Updates

You can check for updates from inside the application. Every update package passes three gates: the Ed25519 signature, then the SHA256SUMS.txt digest, and finally the file's own SHA-256 digest. If verification fails, the update is not installed.

Uninstalling

Control Panel → Programs and Features → KDV Cross-Check → Uninstall. Alternatively run unins000.exe from the installation folder. Uninstalling removes the application and its files completely; the invoice and report files on your computer are untouched.

System requirements

  • Windows 10 or 11 (64-bit)
  • About 250 MB of disk space (including installation)
  • Internet is only needed for licence verification and updates; the comparison itself works offline
